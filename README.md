# Le ST Georges — site vitrine

Site vitrine statique, en une page, pour Le ST Georges à Étroussat.

## Fichiers

- `index.html` : contenu et structure de la page
- `style.css` : mise en forme et adaptation mobile
- `script.js` : menu mobile, galerie et interactions
- `assets/` : photos utilisées par le site, dont la photo de façade fournie
